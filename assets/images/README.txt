Put your photos in this folder.

- Your portrait:  portrait.jpg  (used on the Home and About pages)
- Gallery photos: any name you like, e.g. photo-1.jpg, beach-2026.jpg

Then reference them in ../../posts.js like:

  {
    image: "assets/images/photo-1.jpg",
    caption: "Your caption",
    date: "May 2026",
    location: "Dhaka",
  },

Any size or orientation works — the page adjusts automatically.
If a photo is missing, a neat placeholder is shown instead.
